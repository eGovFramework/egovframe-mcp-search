# 시나리오 00 — 사전 준비 및 설치 검증

## 목적

폐쇄망에 반입한 본 MCP가 OSS LLM 클라이언트에서 정상적으로 인식되고, `egov_search_knowledge` 와 `egov_ddl_assist` 도구 2개가 노출되는지 확인합니다. 이 시나리오가 실패하면 이후 모든 시나리오를 진행할 수 없습니다.

## 사전조건

- 폐쇄망 서버에 Node.js 18 이상 설치
- 본 저장소가 폐쇄망 작업 경로(예: `/opt/egovframe-mcp-search`)에 복사됨
- `node_modules`까지 포함하여 반입했거나, 사내 npm 미러를 통해 `npm install`이 가능

## 절차

### 1) 빌드와 인덱싱

```bash
cd /opt/egovframe-mcp-search
npm install            # 사내 npm 미러가 없으면 사전 반입한 node_modules 사용
npm run build
npm run build-index    # SQLite + LanceDB 지식 베이스 구축
```

성공 시 다음이 만들어져 있어야 합니다.

- `build/index.js`
- `knowledge-base/egovframe.db`
- `knowledge-base/developer_knowledge.lance/`

### 2) MCP 클라이언트 등록

폐쇄망에서 사용하는 OSS LLM 클라이언트의 MCP 설정 파일에 다음과 같이 등록합니다.

```json
{
  "mcpServers": {
    "egovframe-mcp-search": {
      "command": "node",
      "args": ["/opt/egovframe-mcp-search/build/index.js"],
      "env": {
        "EGOVFRAME_TEMPLATE_PATH": "/opt/egovframe-mcp-search/templates",
        "EGOVFRAME_KNOWLEDGE_DB": "/opt/egovframe-mcp-search/knowledge-base"
      }
    }
  }
}
```

### 3) 도구 목록 확인

LLM 클라이언트에서 본 MCP 서버를 활성화한 뒤, **`egov_search_knowledge` 와 `egov_ddl_assist` 2개가 노출되는지** 확인합니다.

| # | 도구 | 분류 |
|---|------|------|
| 1 | `egov_search_knowledge` | 통합 지식 검색(읽기 전용) |
| 2 | `egov_ddl_assist` | 표준용어 기반 DDL 설계/검토 보조(읽기 전용) |

가능하면 `npm run inspector`로 MCP Inspector를 띄워 `Tools` 탭에서 목록과 입력 스키마를 직접 확인합니다.

> 위 2개 외에 다른 도구가 보이거나 2개 중 하나라도 빠져 있으면 빌드본이 갱신되지 않은 상태입니다. 통합 검색으로 흡수된 옛 이름(`search_guide`, `search_knowledge`, `search_standard_terms`, `list_common_components` 등)은 더 이상 등록되지 않으므로 노출되지 않으며, 그 이름으로 호출하면 SDK 가 표준 JSON-RPC `Method not found` 에러를 반환합니다.

### 4) Smoke Test 프롬프트

LLM 채팅창에 아래 프롬프트를 입력해 LLM이 본 MCP 도구를 자동으로 선택하는지 확인합니다.

```text
표준프레임워크에서 "트랜잭션 설정"에 대해 공식 가이드와 저장된 지식을 함께 찾아줘.
```

## 합격 기준

- [ ] `npm run build`와 `npm run build-index`가 외부 인터넷 없이 완료된다.
- [ ] MCP 클라이언트가 본 서버를 인식하고 `egov_search_knowledge` 와 `egov_ddl_assist` 2개를 노출한다(그 외 도구 없음).
- [ ] Smoke Test 프롬프트에서 LLM이 `egov_search_knowledge`를 호출하고 한 건 이상의 결과를 반환한다.

## 실패 시 대응

| 증상 | 1차 확인 |
|------|----------|
| `npm install` 실패 | 사내 npm 미러 주소 또는 사전 반입한 `node_modules` 사용 여부 |
| `build/index.js` 없음 | `npm run build` 로그에서 TypeScript 에러 확인 |
| 도구 목록이 비어 있음 | 클라이언트 설정의 `command`/`args` 절대 경로 확인 |
| 지식 검색 결과 0건 | `EGOVFRAME_KNOWLEDGE_DB` 경로와 `build-index` 실행 이력 확인 |
