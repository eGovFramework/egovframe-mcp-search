# v5.1.0 Beta 릴리스 노트

- 배포일: 2026-11-27
- 패키지 버전: 5.1.0

표준프레임워크 개발에 필요한 자료를 검색하는 MCP 서버, eGovFrame Search(지식검색 MCP)의 최초 배포 버전입니다.

## 주요 내용

- 제공 도구: `egov_search_knowledge` 1개 (`query`, `scope`, `action`, `filters`, `limit`)
- 5가지 검색 범위(`scope`)
  - `guide`: 표준프레임워크 공식 가이드([egovframe-docs](https://github.com/eGovFramework/egovframe-docs))를 의미 기반으로 검색 (문서 조각 약 7,000건)
  - `knowledge`: 포털의 묻고답하기(Q&A), FAQ, 적용가이드 PDF 를 의미 기반으로 검색 (묻고답하기와 FAQ 약 8,400건, 적용가이드 PDF 조각 254건)
  - `components`: 공통컴포넌트 검색과 상세 조회 (의존성, 소스 파일, 8개 DBMS 별 DDL / DML 포함)
  - `compatibility`: 표준프레임워크 버전별 호환 소프트웨어 목록 조회 (약 600건)
  - `all` / `auto`: 모든 출처를 한 번에 검색하거나, `scope` 를 생략하면 서버가 검색할 출처를 결정
- 오프라인 동작: 지식베이스(SQLite + LanceDB)와 임베딩 모델이 패키지에 들어 있으므로 검색할 때 네트워크에 접속하지 않습니다. 의존 패키지도 tgz 에 함께 들어 있어서 폐쇄망에서 설치하고 실행할 수 있습니다.
- 읽기 전용: 도구는 지식베이스의 내용을 바꾸지 않습니다.

## 요구 사항

- Node.js 22 (`>=22 <23`). `better-sqlite3` 의 네이티브 바이너리가 Node.js 22 전용이기 때문입니다. 다른 메이저 버전으로 실행하면 공통컴포넌트와 호환 소프트웨어 조회가 동작하지 않습니다.
- 운영체제와 CPU 에 맞는 배포 파일을 사용합니다. Linux 용 파일은 glibc 기반 배포판용입니다.

| macOS (Intel) | `egovframe-mcp-search-5.1.0-darwin-x64.tgz` |
| Linux x64 (glibc) | `egovframe-mcp-search-5.1.0-linux-x64.tgz` |

## 설치와 등록

배포 파일은 압축을 풀지 않고 `npx` 로 실행하도록 AI 클라이언트에 등록합니다. 클라이언트별 등록 방법은 [설치와 MCP 클라이언트 등록 가이드](../setup/MCP_SETUP_GUIDE.md)에 있습니다.

```bash
npx -y --package=<tgz 파일의 절대 경로> egovframe-mcp-search
```

## 참고

- 이번 버전은 베타 버전입니다. 문제가 있으면 <https://github.com/eGovFramework/egovframe-mcp-search/issues> 에 알려 주세요.
- tgz 의 용량이 약 330MB 라서, `npx` 로 실행하면 서버를 시작할 때마다 20초 정도 걸립니다. 서버 시작 대기 시간이 이보다 짧은 클라이언트(예: 기본값이 10초인 Codex)에서는 대기 시간을 늘려서 사용합니다.
- 패키지에는 지식베이스를 갱신하는 `update` 명령이 들어 있습니다. 이번 버전에서는 동봉된 자료보다 오래된 자료가 갱신 후보로 표시되는 경우가 있으므로, 갱신하기 전에 [지식베이스 구축과 갱신 가이드](../operations/KNOWLEDGE_BASE_GUIDE.md#510-beta-에서-주의할-점)의 주의 사항을 확인합니다.
- 확인했지만 고치지 않고 남긴 문제는 [알려진 문제와 후속 작업](../development/KNOWN_ISSUES.md)에 정리되어 있습니다.
